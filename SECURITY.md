# Security

Please report a vulnerability privately, never in a public issue or pull request.

- Preferred: GitHub's private vulnerability reporting, under this repository's **Security** tab.
- Or email contact@yesid.dev with "Security" in the subject.

Please include what you found and how to reproduce it. Sites built from this starter sign in through a separate service, `yesid.login`; report issues with sign-in or editing there. Do not test against live client sites or login.yesid.dev with accounts or data that are not yours.

There is no bug bounty. I will acknowledge your report, keep you informed, and credit you when the fix ships if you wish.
